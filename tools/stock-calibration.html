PetKit T4 calibration extractor

Drop a full, unencrypted flash dump taken while the stock firmware was installed. The factory weight calibration is read from the NVS partition user_calibrt, namespace T4, key data. The file is read in your browser only; nothing is uploaded.

Same checks as tools/extract_stock_calibration.py: partition table MD5, NVS page, entry and blob CRCs. Anything that doesn't match the known T4 layout is rejected. These values are not used by the ESPHome firmware yet; see docs/stock-calibration.md.
